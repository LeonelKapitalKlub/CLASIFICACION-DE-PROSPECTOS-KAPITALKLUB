# CRM Kapital Klub

Sistema de gestión de prospectos y clientes.

## Stack
- React + Vite
- Supabase (base de datos + autenticación)
- Despliegue en Netlify

## Desarrollo local

npm install
npm run dev

## Build de producción

npm run build

Esto genera la carpeta dist/, que es lo que Netlify publica.

## Configuración en Netlify
- Build command: npm run build
- Publish directory: dist
